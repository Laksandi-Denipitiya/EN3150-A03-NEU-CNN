# EN3150 Assignment 03
## Resource-Constrained CNN for Steel Surface Defect Classification

This project implements and evaluates resource-constrained convolutional neural
networks for classification of steel surface defects using the NEU-CLS dataset.

### Models
- Model A: Standard CNN
- Model B: Lightweight CNN using depthwise separable convolutions
- MobileNetV2
- EfficientNet-B0

### Dataset
NEU-CLS steel surface defect dataset.
